# dedupe

![Node](https://img.shields.io/badge/node-%3E%3D18-brightgreen)
![Dependencies](https://img.shields.io/badge/dependencies-0-blue)

> Remove duplicate lines while keeping order.

Part of the **DevKit-100** collection: 100 tiny, zero-dependency developer tools.

## Install

```bash
git clone https://github.com/ElNeMeR70/dedupe.git
cd dedupe
node index.js <args>
# or link globally
npm link
```

## Usage

```bash
cat list.txt | dedupe
```

## Why

- Zero dependencies, single file
- Works offline, Node 18+
- Easy to read and hack
